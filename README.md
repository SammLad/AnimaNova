# Anima Nova

Plataforma demostrativa para conectar a ciudadanos, rescatistas, refugios y centros de cuidado de fauna.

## Ejecutar el frontend

```bash
cd frontend
npm install
npm run dev
```

La aplicación React ofrece un inicio público, registro ciudadano y paneles diferenciados por rol. Los datos de la demostración se guardan en el almacenamiento local del navegador.

Las cuentas de prueba se crean automáticamente en el navegador. Las contraseñas en texto y el almacenamiento local son únicamente para la simulación: no deben usarse como autenticación de producción ni para información real.
